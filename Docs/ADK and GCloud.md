# Google ADK

Create an Agent : `adk create << agent name >>`

Install Google ADK : `python -m pip install google-adk `

Show adk info:`pip show google-adk`

# GCloud in CLI :

Install gcloud
`brew install --cask gcloud-cli`

Login on Terminal :
`gcloud auth login`

To see the current logged in account : `gcloud auth list`

Set Project : `gloud config set project gen-lang-client-0079349052`
